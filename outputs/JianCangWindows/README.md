# 见藏 Windows 0.36.21

Windows x64 版。双击 `JianCang-Windows-0.36.21-x64-Setup.exe` 安装到当前用户，安装程序会添加桌面快捷方式和开始菜单入口。也可以解压 ZIP，运行其中的 `Install-JianCang.exe` 或直接使用 `JianCang` 文件夹里的便携版。

## 0.36.21 更新

- 安装程序使用固实压缩。便携包减少未使用的 OCR 核心和部分 Chromium 界面语言资源，FFmpeg 对应源码改用 XZ 压缩。
- Chromium 自带提示提供简体中文、繁体中文和英语资源，其他系统语言没有匹配时回退英语。

## 0.36.20 更新

- **同帖多图采集**。可预览并勾选当前帖子或网页已加载的图片，单批最多 40 张。可按规则保存或手选集合，部分失败时可以只重试失败项。采集插件 1.4.1 将各素材库的常用集合优先显示。
- **自动归档**。在「见藏 → 浏览器采集」添加规则，按网站、网址关键词和素材类型选择素材库、集合与标签。按列表顺序使用第一条命中规则，手选目标时以当前选择为准。
- **导出预设**。结构化导出和灵感板可复用集合层级与 CSV 清单设置，图片工具可复用格式、最长边和画质设置。

## 0.36.19 更新

- **AI 整理建议**提供「勾选全部」和「勾选空白项」两个操作。前者选中当前可应用的名称、标签和备注。后者选中缺失资料，也包含明显乱码、长编号和采集网站生成的文件名。可读的名称保留，每个字段仍可单独勾选。

## 0.36.18 更新

- **AI 整理建议**。全部勾选时按字段补齐缺失资料。已有的名称、标签和备注可保留，也可以手动勾选对应的建议。所选建议应用成功后，窗口自动关闭。
- **批量重命名**。编辑规则时更快显示最终文件名。点击「重命名」即可应用，集合内的同名编号会显示在对照表中。

## 0.36.17 更新

- **采集历史**。在「见藏 → 浏览器采集」查看最近保存的项目。原帖地址、实际图片地址和入库像素尺寸分开显示。使用采集插件 1.3.6 时，图片地址还可记录浏览器重定向后的最终地址。
- **抖音拖图**。采集插件 1.3.6 支持从透明按钮覆盖的抖音图文轮播直接拖动当前照片。普通点击和翻页保留原操作。
- **批量重命名预设**。在批量改名窗口保存常用规则。套用预设后自动预览最终名称，确认后应用。
- **重复素材合并**。同一可写本地库内，文件内容完全相同的素材可以在清理前预览并合并标签和集合。确认后保留选定原件，其余移入回收站。

## 0.36.16 更新

- 批量重命名在编辑规则时显示原名称和最终名称，包括扩展名和同名编号。确认后才写入素材库。
- 采集插件 1.3.5 在见藏确认保存后播放简短提示音，可在插件选项中关闭。

## 0.36.15 更新

- 恢复从素材缩略图放大进入大图预览的动画。原图读取较慢时先显示缩略图，原图解码后再接替。
- 采集插件升级到 1.3.4。
- 采集图片时记录实际像素尺寸。有确切帖子链接时保存帖子的完整地址，详情栏直接换行显示长网址。
- 在抖音图文轮播中，可按住并拖动当前显示的图片采集，包括网页未提供原生拖动的图片。

## 0.36.14 更新

- GitHub 附件服务返回 HTTP 400 时，会重新取得下载地址再试一次。若续传请求仍被拒绝，则尝试从头下载。成功下载的更新包仍须通过签名清单的 SHA-256 校验。
- 采集插件 1.3.3 在拖图开始后延迟约 200 毫秒显示面板。把图片拖进保存区或集合并松手时，面板立即关闭。图片在后台导入，成功后显示短提示，失败可在提示中重试。

## 0.36.13 更新

- 采集插件 1.3.2 在拖图起点附近打开面板。靠近窗口边缘时会调整位置，拖动期间面板保持在打开的位置。通过工具栏打开采集时，优先使用最近的网页鼠标位置。
- 采集面板加宽，集合列表可同时显示更多项目。在较小的窗口中，面板收窄到可见范围，集合列表可以滚动。
- 已从见藏提供的扩展文件夹加载插件的用户，安装见藏更新后，支持自动更新的插件会在采集空闲时应用新版。

## 0.36.12 更新

- GitHub 附件下载地址失效时，见藏会重新取得一次下载地址，并尽量从已下载进度继续。
- 更新请求失败时会显示 HTTP 状态。使用官方通道时，也可点击「在浏览器下载」打开发布页，下载并运行 Setup.exe。

## 0.36.11 更新

- **插件随见藏更新**。从「见藏 → 浏览器采集 → 打开扩展文件夹」加载插件后，见藏更新会带上新插件，Edge 或 Chrome 会在采集面板关闭且没有正在进行的采集时自动加载新版。浏览器配对和拖图设置会保留。
- **首次切换**。已从见藏提供的目录安装插件的用户，本次更新后需要在浏览器扩展页重新加载一次。此前直接从 ZIP 解压安装的用户，请改为加载见藏提供的目录。

## 0.36.10 本地版

- **默认采集位置**。首次使用时，打开可写素材库后自动开启采集。已有默认库、默认集合及关闭状态会保留。
- **拖图采集**。本地浏览器插件 1.3.0 默认开启拖图。首次松手采集时在见藏确认连接，图片会继续保存到所选位置。插件选项可关闭拖图采集。
- **安装或更新本地扩展**。在见藏菜单打开「浏览器采集 → 打开扩展文件夹」。第一次安装时在 Edge 的扩展管理页开启开发人员模式并加载该文件夹。已从此文件夹安装的扩展，覆盖安装见藏后在 Edge 扩展管理页点「重新加载」即可。

## 0.36.9 更新

- **当前版本**。打开「软件更新」可直接看到正在运行的版本号，检查失败时也会显示。
- **网页拖图采集**。更新至浏览器插件 1.2.0，并在插件中启用拖图采集。授权的网站上开始拖动图片时即弹出收集面板，松手可保存到默认位置或某个集合。
- **采集结果**。图片写入素材库后才显示已保存。读取原图或写入失败时，可看原因并在面板重试。

## 0.36.8 更新

- **独立更新窗口**。点左上角见藏菜单的「软件更新」即弹窗检查。下载进度、速度、已下载大小和安装包大小都在窗口里。关闭窗口后下载继续，再次打开可查看进度或取消。
- **见藏浏览器插件**。Edge 和 Chrome 可从工具栏打开网页采集面板，将图片拖到默认位置或指定集合。网页右键仍可快速采集图片、链接和网页。
- **首次授权**。在见藏菜单的「浏览器采集」里选择默认位置并启用，然后打开扩展文件夹。在浏览器扩展管理中开启开发者模式，加载解压后的扩展。点击工具栏见藏图标，在桌面见藏确认「允许连接」即可。之前已经授权的扩展可在浏览器的扩展管理里重新加载，保留现有连接。

## 0.36.7 更新

- 安装时在后台运行安装脚本。安装完成页默认勾选「启动见藏」。取消勾选再点「完成」即可只退出安装器，关闭完成页也会直接退出安装器。
- 从 0.36.6 或更早版本升级时，使用新版 Setup.exe 覆盖安装即可看到新完成页。旧版内置更新仍会按旧流程安装此次更新。

## 0.36.6 更新

- **按描述找图**。在图库工具栏点击「按描述找图」，可用「黄昏逆光的人像，背景有树」这样的描述查找画面。使用已配置的 LM Studio 或支持图片输入的 OpenAI 兼容模型，结果按相关性排序，画面摘要保存在本机供下次复用。图库范围较大时可选分组，每组最多 120 张。
- **浏览器一键采集**。在左上角见藏菜单打开「浏览器采集」，选择接收用的可写库和集合并启用。点击「打开扩展文件夹」，在 Edge 或 Chrome 的扩展管理页开启开发者模式并加载该文件夹，再用见藏生成的连接码配对。见藏运行时，点浏览器扩展图标收藏当前网页链接，或从右键菜单采集网页、图片和链接。
- **视频多段裁剪**。在「裁剪视频」里可选取最多 12 段，调整顺序后合并导出成一个视频。CSV 和 SRT 备注按合成后的视频时间重新计算，源视频保留。

## 0.36.5 更新

- **Eagle AI 建议与批量整理**。在 Eagle 中打开同一份库，并在见藏开启双向同步。可把选中的名称、标签、备注建议写回 Eagle，也可批量改名、增减标签、修改评分、备注、来源网址和集合归属。
- **iCloud 自动导入**。监视文件夹可选已开启双向同步的格式 6 见藏库及集合。见藏运行期间会扫描来源文件夹，通过原有队列提交并保留来源文件。
- **更新断点续传**。在线下载因断网中断后可继续，重启后同一个更新包仍可续传。通道不支持续传时会重新下载，主动取消会清理本次缓存。
- **可编辑灵感板工程**。可导出和导入 `.jiancangboard`，保留顺序、说明和素材引用。工程文件不包含原件，连接同一素材库后可查看图片并继续编辑。
- **覆盖安装**。安装程序会请求已安装的见藏正常关闭，退出后继续安装。如果旧窗口需要处理或长时间未关闭，安装会提示重试。

## 0.36.4 更新

- **跟随 Windows 系统代理**。在线版本检查和安装包下载都使用系统代理，包括 GitHub 附件跳转。使用 Clash Verge 时开启「系统代理」即可。
- **更新失败后继续操作**。代理无法连接或断网时，更新会显示处理提示。下载失败可直接重试，取消下载会清理临时文件。

## 0.36.3 更新

- **见藏菜单**。点击左上角 Logo 可打开素材库、导入队列、灵感板、主题、帮助等常用入口。帮助面板保留版本号和快捷键。
- **软件更新**。点击菜单里的「软件更新」立即检查。下载时显示进度、速度、已下载大小和安装包总大小。
- **安装与卸载**。在菜单里查看和打开安装位置、安装便携版、修复快捷方式或卸载。默认安装在 `%LOCALAPPDATA%\Programs\JianCang`，卸载保留素材库和应用数据。

## 0.36.2 更新

- **一键检查更新**。在「帮助」点击「软件更新」后立即检查，结果、下载及安装按钮都显示在同一个面板中。
- **选中素材**。瀑布流和列表的选中框独立绘制，点选时保留原先和新选中的两张缩略图。

## 0.36.1 更新

- **软件内更新**。支持从 GitHub Releases 检查和下载更新。在「关于见藏 → 软件更新」查看新版本，选择「下载并安装」后，见藏会校验更新包并完成安装。

## 0.36.0 更新

- **点击素材预览**。切换详情时优先展示已加载的缩略图，原图解码期间保留可见画面。
- **Eagle 双向同步**。在 Eagle 4.0 Build 21 或更新版本中打开同一份库，然后在见藏右侧详情或素材库管理中开启双向同步。名称、标签、备注、来源网址、集合归属和评分可直接写回。关闭开关后该库恢复只读。
- **复制色板**。右栏可以复制整组 HEX 色值或 PNG 色条。点击单个色块可以查找相近颜色。
- **查找同来源网站**。右键有来源网址的素材即可查找当前库范围内来自同一网站的素材。搜索范围菜单也可选择「来源网站」并输入域名。

## 0.35.1 更新

- 点击右上角的「?」或按 `F1`，在「关于见藏」查看当前运行的版本号。

## 0.35.0 更新

- **大图和详情预览**。后台刷新同一张照片时保留当前画面，等新图解码完成再替换。
- **置顶参考窗**。窗口按画面的绘制节奏等比缩放，连续滚动时以鼠标位置为锚点。图片可以放大到超过桌面工作区。
- **全局界面**。图库、详情、预览、菜单、弹窗、灵感板和编辑工具统一为暖炭暗房及暖白主题。下拉选项、勾选框、滑杆和主要操作按钮跟随主题。

## 0.34.0 更新

- **首次打开大图**。图库和预览共用固定高度的 Windows 标题栏。原图淡入期间保留已经显示的缩略图，滚轮缩放与平移会同步带动两层画面。
- **置顶参考窗**。按住时停止进行中的缩放，拖动期间锁定窗口宽高。两次短按仍可回到 100%。复制小图时保留原有像素尺寸。
- **框选和弹窗**。右栏始终把刚框住的图片叠在最上面，松手后保持顺序。弹窗打开时，点击主界面或大图的应用顶栏也可以关闭弹窗。

## 0.33.0 更新

- **大图和实况**。打开大图时，缩略图保持可见直到原图解码完成。预览顶栏保留见藏标志与名称。实况从封面渐变进入运动画面，结束后渐变回封面。
- **置顶参考窗**。首帧就绪后显示，滚轮连续等比缩放。按住图片时停止未完成的缩放，拖动可移动窗口。双击回到 100%，过大的照片以桌面可见的最大比例显示。右键可复制图片、调整尺寸和不透明度、切换置顶或关闭。
- **框选和菜单**。框选的新照片逐张叠到右栏。集合右键直接点色板改色，可撤销。单图的裁切、编辑和格式转换统一到「图片工具」。点击应用内对话框外可以关闭，已有操作中的关闭保护继续生效。
- **智能查找**。可按主色、包含任一颜色或包含全部颜色筛选，可调整 HEX 匹配的接近程度。OCR 可查短语、全部搜索词，或筛选有字、无字。应用时在本机补扫缺少的索引，组合条件可存为智能集合。

## 0.32.0 更新

- **框选与批量资料**。拖动框选时，右栏按原比例实时叠放最多七张预览，并显示所有选中项的总大小。可查看共有标签、集合，以及评分、备注和来源网址。批量保存只写入可编辑素材。
- **大图与实况**。返回键对齐预览区左边。照片、视频和播放器控件跟随黑白主题。点击「实况」播放或停止，在预览中右键选择「循环播放实况」。
- **连续整理**。右键切换素材时保留缩略图和滚动位置。后台检测到内容没变时跳过界面更新。收藏或资料同步时，已有图片和视频预览保持在位。
- **参考窗与拖出**。在图片任意处按左键可移动参考窗。滚轮缩放时窗口随图片等比缩放，`Ctrl` 加滚轮调不透明度。跨软件拖动使用半透明缩略图。
- **右键菜单**。素材菜单新增「复制文件」和「删除」。可写库的集合菜单支持重命名、新建同级和子文件夹、设置颜色及删除。右键素材会收起已打开的集合菜单。

## 0.31.0 更新

- **窗口与详情栏**。最小化、最大化和关闭并入主工具栏。详情栏有长名称时自动换行，可直接编辑并保存。
- **置顶参考窗**。画面只显示图片。按住 `Ctrl` 滚动调节不透明度，拖动图片上沿移动窗口，按 `Esc` 关闭。
- **框选和大图**。在素材间的空白处拖动框选，右侧叠放所选素材的预览。大图缩小后也能拖动位置，预览重新加载会保留当前缩放和位置。
- **查找相似图片**。从素材右键菜单直接查找当前浏览范围内的相似图片，过程中可以取消。
- **右键快捷操作**。素材可以用默认应用打开，并按写入权限收藏、评分和加入集合。集合可以加入常用、复制名称或导出含子集合的素材。
- **直接拖入**。拖到素材区后自动进入当前可写库或集合。「所有素材库」下只有一个可写库时会导入该库。有多个可写库时，可以拖到左侧的目标库或集合。
- **拖出文件**。直接拖素材卡片或右侧图片预览，可将校验后的文件副本交给支持文件拖放的应用。

## 0.30.0 更新

- **精确搜索和排除词**。用双引号匹配连续短语，例如 `"海边 日落"`，用前置减号排除词，例如 `-草稿`。支持中文引号、按字段搜索和保存到智能集合。
- **快速复用标签**。在右栏点击「＋」并输入时，会建议同一素材库已有的标签。点击或用方向键和回车选取，确认保存后写入素材。
- **导入队列筛选**。在所选素材库内查看各个状态的任务数，可以按文件名或失败原因搜索。筛选后仍可对相应任务重试或取消。
- **常用和最近集合**。打开「查找集合」，空搜索时优先显示已标记的常用集合和最近打开的集合。标记保存在本机，可跨库使用。

## 配置更新通道

更新通道需要同时提供 `jiancang-windows-x64-update.json` 和清单指向的 Windows x64 ZIP。可以使用已公开的 GitHub Releases、本机文件夹、已同步到本机的共享目录，或托管这些文件的 HTTPS 目录。

在线检查和下载更新会跟随 Windows 系统代理。使用 Clash Verge 时，打开「系统代理」即可，本机更新文件夹直接读取。

在 GitHub 发布时，将 ZIP 和同一次构建生成的签名清单作为同一个 Release 的附件，上传完两份附件再发布并设为最新。在「软件更新」中可直接填写 GitHub 仓库网址。安装版会在启动后及运行期间检查更新，可以在软件内关闭自动检查。便携版可通过安装包切换到安装版。

- **见藏同步库**。在 Windows 启用 iCloud Drive，选择手机连接的同步文件夹，即包含 `library.json`、`blobs` 和 `changes` 的那一层。支持同步格式 1 至 6。云端原件尚未取回时，可以打开「取回原件」查看进度和重试。
- **Eagle 库**。从左侧「素材库」旁的三点菜单进入「添加库」，选择 Eagle 的 `.library` 根目录。见藏直接读取原件和现有文件夹、标签、评分、备注，按只读方式打开。
- 左侧「所有素材库」可同时浏览和搜索已添加的见藏库、Eagle 库。点击某个库可单独浏览，该范围下会显示相应的文件夹和素材。上次选择的范围会在重启后恢复。
- 左侧「素材库」旁的三点按钮或 `Ctrl+L` 打开管理。如果目录搬了，可重新定位。从列表移除只断开连接。
- 已连接的库有变化时在后台刷新对应库。缩略图缓存保存在本机，原件暂未到齐时可显示已有缩略图。预览失败可点「重新读取」，也可以从素材右键菜单重试。

## 导入和整理本地库

- 点击「导入」选择文件或文件夹。拖进素材区时，文件会直接进入当前可写库或集合。打开「所有素材库」时，如果有多个可写库，可直接拖到左侧目标库或集合。文件夹层级会建成子集合。选择图片或网址后可粘贴导入，网址会保存成可打开的链接素材。
- 「导入」显示进度和失败原因。失败条目可以单独重试，重开应用会接着处理未完成的任务。
- 左侧「监视文件夹」可选择来源目录，并将新文件自动导入本地库或开启双向同步的格式 6 见藏库。可指定集合、是否扫描子文件夹和已有文件，也可暂停、恢复或手动扫描。来源文件保留在原处。
- 从素材右键菜单、详情栏或多选底栏可以复制到其他可写库。复制失败后，可从导入队列重试。
- 素材右键可用系统默认应用打开支持的原件格式，也可以复制文件到系统剪贴板。可写库中的素材可通过右键快速收藏、评分、加入同库集合或删除。删除时会确认并移入回收站。
- 集合右键可加入常用、复制集合名称、导出本集合和子集合内的素材。可写库还支持重命名、新增同级或子文件夹、移动文件夹、设置颜色和删除。常用集合在「查找集合」中优先显示。
- 在详情栏直接编辑可写素材的名称、标签、备注、网址和集合。多选后可批量改标签、评分、收藏和集合。批量重命名先显示预览，再按预览结果应用；同名加序号。
- 集合标题旁的加号创建集合，集合行的菜单可创建子集合。删除集合及其子集合会保留其中的素材。
- 删除素材需确认，确认后移到回收站。回收站可单条或批量恢复。工具栏的撤销按钮或 `Ctrl+Z` 可撤销当前本地库上一步整理。

## 浏览和预览

- 瀑布流、等高和列表视图都可连续滚动。列表显示缩略图、文件名、格式、大小、尺寸、评分和日期，点击列标题可排序。切换布局可沿用当前筛选与多选。网格有缩略图大小滑杆，列表按行浏览。点击素材在右栏看完整预览，可拉动分隔线调整详情栏宽度。
- 从素材间的空白拖动可以框选。按住 `Ctrl` 单击可增减选中项，按住 `Shift` 单击可连续选择，`Ctrl+A` 全选当前结果。多选时右栏会叠放部分预览，也可从右键菜单和底栏导出或整理所选素材。
- 双击素材，或选中后按空格，在中间看完整大图。滚轮或滑杆缩放，缩小和放大时都可拖动画面。`←` / `→` 切换素材，`F` 切换专注模式，再按空格或 `Esc` 回到原来的列表位置。
- 图片从对应缩略图展开，返回时在缩略图仍可见的情况下缩回。滚轮以指针位置为缩放中心。缩略图加载失败时会尝试以可解码的原件补上，包含 WebP。
- 从底栏导出所选素材，可把多个库中的原件一起保存到选定文件夹。同名副本会加序号。
- 选中可编辑的素材后按 `F2` 可进入单个或批量重命名预览。
- 选择两张图片后点「对照」，可并排查看构图和细节，支持联动缩放与拖动。
- 左侧「未标注」查看没有标签的素材，「最近查看」可翻回本机近期打开的大图，浏览记录会在重启后保留。
- 视频进入大图时自动播放。底部提供进度、音量、倍速和循环播放。视频预览内按空格可播放或暂停，按 `Esc` 返回素材页。
- 视频会记住上次播放进度。底部可在当前时间点写备注，点备注时间跳回对应位置，也可以导出当前帧为 PNG。播放进度和时间点备注保存在这台电脑。
- 时间点备注面板支持导出 CSV 或 SRT。CSV 保留每条备注的精确时间码，SRT 可作为参考字幕导入支持该格式的剪辑软件。每段最多显示三秒，遇到下一条备注或视频结尾时提前结束。
- 工具栏的月亮或太阳按钮切换黑白主题，重启后保留选择。
- 搜索支持名称、标签和备注。右侧详情栏可导出原件或在资源管理器中定位。打开 `.livp` 实况照片后点「实况」播放或停止，右键可设置循环播放，也可导出完整原件。
- 点击「筛选」可同时按格式、画面比例、标签、评分和添加日期缩小范围。筛选可与当前集合、关键词和文件类型一起使用。

## 桌面取用

- 右键素材可打开预览、重新读取、导出或在资源管理器中定位。图片也可单独打开置顶参考窗。
- 直接从素材卡片或右侧图片预览拖到其他软件。首次拖动时请按住鼠标等副本准备好。也可从素材右键选择「复制文件」，在资源管理器或支持文件粘贴的应用中粘贴。两种方式的校验副本均保存到「下载 → 见藏拖出」。
- 多选后点击「导出选项」，可以平铺原件或按素材库和集合层级导出，并选择同时生成 CSV 清单。每次导出会创建新目录。同名素材会加序号，已有文件保留。

## 网页离线阅读

- 在网址素材的右键菜单或详情栏打开「离线阅读」，然后点击保存。见藏会把可读取的正文和链接存到本机，断网时仍可查看，也可以更新或删除保存版本。
- 登录后或依赖脚本加载的页面可能无法保存正文。阅读窗口提供在浏览器打开原网页的入口。同站跳转受支持，跨站跳转时可先打开原网页，再保存最终网址。

## 智能集合、找图和灵感板

- 设置搜索词和筛选条件后，点侧栏「智能集合」旁的加号保存。每次打开都会用当前素材重新计算结果。智能集合的菜单可重命名、用当前筛选更新或删除。
- 「智能查找」可分析当前库或集合内图片的主色，也可识别简体中文和英文。文字分析在本机运行。识别后可用搜索栏或「图片中包含的文字」找图，详情栏可查看并复制原文。
- 在图片的右键菜单中选择「查找相似图片」，会立即比较当前范围。结果支持双图对照和多选整理。只查找重复画面时，可使用侧栏「重复素材整理」。
- 在工具栏打开「灵感板」，可从当前素材结果选图，也可分批从多个库加入。卡片可拖动排序、写说明，并导出长 PNG 或多页 A4 PDF。灵感板和智能集合保存在本机。

## 批量 AI 整理建议

- 在「管理素材库 → AI 接口设置」选择 OpenAI 兼容接口或「LM Studio（本机）」。兼容接口可填 API 基地址或完整的 `/chat/completions` 地址。按服务要求填写密钥。
- 使用 LM Studio 时，在 Developer 页面启动本机服务器，保留默认地址 `http://127.0.0.1:1234/v1` 或填入实际端口。点击「读取模型」，选择支持图片输入的模型后保存。如果服务器启用了令牌认证，请同时填写访问令牌。两种服务各自保存地址、模型和密钥。
- 从素材右键菜单或多选底栏打开「AI 整理建议」，确认发送后才会把所选图片的缩略图交给配置的服务。建议包含标题、标签和备注，可逐张勾选字段并确认写入。
- 失败项可以单独重试。批量写入同一本地库后可撤销，本机标签会与新标签合并。Eagle 库开启双向同步并在 Eagle 内打开同一份库后，可应用建议到原素材。

## 标签管理与重复素材整理

- 左侧「标签管理」可以搜索所选库的标签、查看各标签的使用数量，也可点标签筛选素材。在可写库中，重命名、合并和移除标签都会先显示影响数量，并在确认后应用。本地库可撤销。
- 左侧「重复素材整理」可扫描当前浏览结果。查找完全重复会校验候选原件的字节，查找相似图片会分析画面。结果会标明「完全重复」「重复画面」或「相似图片」，并保留各自的素材库来源。
- 分组结果可选两张图片对照。选中要移到回收站的可写素材后，需要再次确认，并保留一份可读取的原件。扫描失败的素材库可单独重试，回收站可恢复素材。

## 与 iPhone 或 iPad 双向同步

1. 在 Windows 登录同一个 Apple 账户并开启 iCloud Drive，添加手机上已连接的见藏同步文件夹。
2. 进入这个同步库，从底部「同步状态」打开设置。同步格式为 6 时，点击「开启双向同步」。格式 1 至 5 可继续浏览，可在 iPhone 或 iPad 的多端同步设置里升级到格式 6。
3. 开启后，可从 Windows 向同步库导入素材，并修改名称、标签、备注、来源、评级、收藏和集合，也可移到回收站或恢复。导入队列显示已接收，是否还有变更待提交可在「同步状态」查看。
4. 「立即同步」重试本机待提交的变更并刷新读取。已写入共享文件夹的文件由 iCloud Drive 继续上传。「取回原件」负责读取这个库里的云端原件。

格式 6 的云端文件名及集合路径由负责整理的设备更新。Windows 可修改素材名称或集合，等负责整理的设备完成同步后可以看到对应路径变化。视频、音频和部分图片的预览取决于系统编解码支持。

在 Mac 上开发时，可用同版本 Electron 启动此目录。使用 Node 24 运行 `node --test tests/*.test.cjs`。Windows 便携包通过仓库 `work/build/package-jiancang-windows.py` 生成。脚本使用 macOS 的 `sips` 生成 Windows 图标，并通过 Node.js 或本机 Electron 嵌入和校验图标资源。
